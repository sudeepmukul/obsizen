# ⚡ Installation

## Clone the repository

```bash
git clone https://github.com/sudeepmukul/obsizen.git
cd obsizen
```

## Install dependencies

```bash
npm install
# or
pnpm install
# or
yarn install
```

## Run locally

```bash
npm run dev
```
