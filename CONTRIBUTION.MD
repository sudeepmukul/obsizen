# Contributing to OBSIZEN

Thank you for your interest in contributing to OBSIZEN!

## Getting Started

1. Fork the repository.
2. Clone your fork.

```bash
git clone https://github.com/your-username/obsizen.git
```

3. Create a virtual environment.

```bash
python -m venv myvenv
```

4. Install dependencies.

```bash
pip install -r requirements.txt
```

## Creating a Branch

Please create a new branch for every feature or bug fix.

Example:

```bash
git checkout -b feature/filename-retrieval
```

## Coding Guidelines

* Follow PEP8.
* Add comments for non-trivial logic.
* Keep functions modular.
* Prefer config-driven behavior.

## Pull Requests

Please ensure:

* Code runs successfully.
* No existing functionality is broken.
* README/config examples are updated if necessary.

## Reporting Bugs

Please include:

* Python version
* Error traceback
* Steps to reproduce
* Relevant configuration

Thank you for helping improve OBSIZEN
